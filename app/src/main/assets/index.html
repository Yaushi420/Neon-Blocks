Add your own songs

Seven beat-cut built-in tracks are included. Enable or disable them below. Set a separate maximum speed for each song and use TEST MAX to preview it. Imported songs get the same speed control. One random enabled track is selected per game, and its tempo rises smoothly with the actual falling speed.

Controls: tap = rotate, swipe left/right = move, swipe down = soft drop. Once a downward gesture is recognized, horizontal movement is locked for the rest of that swipe. Quick downward flick or double tap = animated hard drop, swipe up or tap HOLD = hold piece.
